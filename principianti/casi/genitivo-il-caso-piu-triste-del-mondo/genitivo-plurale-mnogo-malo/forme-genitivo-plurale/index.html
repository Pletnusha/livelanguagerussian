ФОРМЫ РОДИТЕЛЬНОГО МНОЖЕСТВЕННОГО ЧИСЛА

Le forme del genitivo plurale

МУЖСКОЙ РОД: -ОВ

Maschile, desinenza zero → -ов · фонтан → фонтанов, парк → парков, ресторан → ресторанов

МУЖСКОЙ РОД НА -Й: -ЕВ

Maschile in -й → -ев · трамвай → трамваев, край → краёв

МНОЖЕСТВЕННОЕ НА -ЬЯ: -ЬЕВ

Plurale in -ья → -ьев · стулья → стульев

ЖЕНСКИЙ РОД НА -А / -Я

Femminile in -а / -я → desinenza zero · улица → улиц, гостиница → гостиниц, кастрюля → кастрюль

СРЕДНИЙ РОД НА -О / -Е

Neutro in -о / -е → desinenza zero · озеро → озёр, окно → окон, полотенце → полотенец

СУФФИКС -К-: -ОК

Femminile con suffisso -к- → -ок · площадка → площадок, остановка → остановок, тетрадка → тетрадок

СУФФИКС -К- ПОСЛЕ ШИПЯЩИХ: -ЕК

Suffisso -к- dopo una sibilante → -ек · чашка → чашек, ложка → ложек, крышка → крышек

Ь И ШИПЯЩИЕ: -ЕЙ

Segno morbido o sibilante finale → -ей · площадь → площадей, день → дней, нож → ножей, овощ → овощей

ОСОБЫЕ ФОРМЫ

Forme particolari e sostantivi indeclinabili · люди → людей, дети → детей, море → морей · пальто, кофе
