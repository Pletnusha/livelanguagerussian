ФОРМЫ РОДИТЕЛЬНОГО МНОЖЕСТВЕННОГО ЧИСЛА

Le forme del genitivo plurale

МУЖСКОЙ РОД НА СОГЛАСНУЮ

Maschile in consonante (desinenza zero) → -ов · парк → парков, фонтан → фонтанов, ресторан → ресторанов
In arrivo

МУЖСКОЙ РОД НА -Й

Maschile in -й → -ев · трамвай → трамваев, музей → музеев, край → краёв

In arrivo

МНОЖЕСТВЕННОЕ ЧИСЛО НА -ЬЯ

Plurale in -ья → -ьев · стул → стулья → стульев, дерево → деревья → деревьев

In arrivo

ЖЕНСКИЙ РОД НА -А / -Я

Femminile in -а / -я → desinenza zero · улица → улиц, гостиница → гостиниц, кастрюля → кастрюль

In arrivo

СРЕДНИЙ РОД НА -О / -Е

Neutro in -о / -е → desinenza zero (ma: море → морей) · озеро → озёр, окно → окон, полотенце → полотенец

In arrivo

ЖЕНСКИЙ РОД С СУФФИКСОМ -К-

Femminile con suffisso -к- → -ок · площадка → площадок, остановка → остановок, тетрадка → тетрадок

In arrivo

СУФФИКС -К- ПОСЛЕ ШИПЯЩИХ

Suffisso -к- dopo una sibilante → -ек · чашка → чашек, ложка → ложек, крышка → крышек

In arrivo

МЯГКИЙ ЗНАК НА КОНЦЕ

Sostantivi in -ь (maschili e femminili) → -ей · площадь → площадей, день → дней, тетрадь → тетрадей

In arrivo

ШИПЯЩАЯ НА КОНЦЕ

Sostantivi con sibilante finale → -ей · нож → ножей, овощ → овощей, ключ → ключей

In arrivo

ОСОБЫЕ ФОРМЫ

Forme particolari e sostantivi indeclinabili · человек → людей, ребёнок → детей, друг → друзей · пальто, кофе
